# 참는 데도 용량이 있습니다

Python + pico2d로 만드는 단일 원형 경기장 액션 게임.
현재는 이미지 없이 경기장·플레이어 크기와 이동을 확인하는 단계입니다.

## 실행

Python 3.13과 `requirements.txt`의 pico2d를 사용합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

이 작업 PC에는 검증용 Python 3.13.11을 `.scratch/python` 안에 준비했습니다.
VS Code의 기본 빌드 작업(Ctrl+Shift+B)은 해당 Python으로 데이터를 검증하고 실행합니다.
다른 PC에서는 설치한 Python 인터프리터를 선택하고 `main.py`를 실행하면 됩니다.
검증용 도구와 내려받은 강의 저장소는 Git 및 배포 대상에서 제외합니다.

- 현재 모니터 해상도의 전체화면으로 시작합니다.
- WASD: 이동. 대각선 속도 보정 적용.
- ESC: 이 크기 확인용 프로그램 종료. 최종 게임의 일시정지는 후속 단계입니다.
- 다른 창으로 전환하면 이동 입력을 비우고 멈춥니다.
- 청록색 직사각형이 플레이어이자 히트박스입니다.
- 경기장 경계에는 직사각형의 하단 절반만 사용합니다. 가운데 선 아래 영역이
  원 안에 남으며, 상단 절반은 캐릭터의 키와 시점을 고려해 경계를 넘을 수 있습니다.
- 격자 한 칸은 1m, 강조선 간격은 5m입니다. 노란 사각형은 입구 위치 표시입니다.

## 확정한 크기

| 항목 | 기준 | 높이 1080 화면 |
| --- | --- | --- |
| 원형 경기장 지름 | 화면 높이 × 1.75 | 1890px |
| 플레이어 높이 | 화면 높이 × 0.05 | 54px |
| 플레이어 너비 | 플레이어 높이 × 0.5 | 27px |

게임 안에서는 화면 세로를 36m로 환산합니다. 경기장 지름 63m, 플레이어는
0.9m × 1.8m입니다. 위치와 판정은 m, 이동 속도는 m/s, 경과 시간은 s로 다루며
그릴 때만 화면 크기에 맞춰 픽셀로 환산합니다. 속도는 강의 예제의 7km/h를
이동 확인용으로 사용하며, 전투 밸런스는 아직 확정하지 않았습니다.

## 강의 방식과 개발 흐름

분석 근거와 적용 내용은 [강의 적용 기록](docs/lecture-notes.md)에 정리했습니다.

- `main.py`: 시트 검증 및 전체화면 시작·종료.
- `game_framework.py`: 모드 스택, 이벤트 → 갱신 → 그리기, 실제 경과 시간 측정.
- `game_world.py`: 레이어별 객체 관리.
- `play_mode.py`: 크기 확인 화면의 객체 생성과 입력 전달.
- `arena.py`, `player.py`, `camera.py`: 객체별 클래스.
- `data/scale.json`: 크기와 속도의 원본 데이터 시트.
- `tools/generate_data.py`: 빈 셀·수치·참조 검증 후 `game_data.py` 생성.

```powershell
python tools/generate_data.py
python -m unittest discover -s tests -v
```

검사는 화면을 열지 않는 SDL dummy 드라이버를 사용합니다. 실제 pico2d 렌더링,
키 입력 전달, 해상도별 크기, FPS별 이동 거리, 대각선 보정, 원과 직사각형의 경계,
카메라 제한, 포커스 상실을 확인합니다. 전체화면에서의 육안 플레이 검증과는 구분합니다.
`shots`에는 검사 중 실제 렌더 버퍼에서 캡처한 화면을 저장합니다.
