# 방패 방향과 패링 동작 검토

사용자 확정: 방패는 주인공 자신의 왼쪽 옆을 향한다. 패링은 왼팔을 앞으로 끌어오며
방패로 약간 아래에서 위로 올려치고 몸을 살짝 수그리는 동작이다.
근접 적은 칼끝이 몸 정면 위를 향하는 준비 자세를 사용한다.

`shield-attack-motion-review.blend`는 실제 메시의 연속 변형과 키프레임을 포함한다.
1~25프레임에서 기본 자세 → 전방 이동 → 올려치기 → 회수 → 기본 자세를 확인한다.
`parry-motion.gif`는 실제 3D 렌더로 구성한 반복 확인 영상이다. 시작과 끝의 정지 시간은
검토 편의를 위한 것이다. 게임의 패링 시간·1초 잠금·공격 판정은 변경하지 않았다.
시안 타이밍과 관절 목표는 `data/art_motion.json`에 보존했다.

왼쪽은 화면 기준이 아니라 캐릭터 기준이다. 좌우 반전 없이 방패 자체를 90도 회전한다.
팔은 상완·전완의 길이로 도달 가능한 관절 목표를 계산하고, 연결 부위를 연속 변형한다.
현재는 모션 검토용 메시 애니메이션이며, 최종 게임용 도트 이미지와 전체 동작 리그는 아니다.

검증: 팔 목표 도달 가능성, 프레임 순서, 시작·종료 동일 자세, 투명 렌더 잘림,
정면·측면 방패 방향과 칼끝 방향, 주요 패링 자세를 확인했다.
모델 원본 v1은 보존한다. 게임 적용은 외형·동작 승인 후 진행한다.

배경 관련 확정 사항도 유지한다: 기존 반경 31.5m 이동 경계 바깥에 물을 두르고,
상하좌우 네 다리는 적 전용 입구로 사용한다. 관객석은 플레이어 체격에 맞춰 보정한다.
물과 다리를 반영한 배경 수정은 아직 별도 작업으로 남아 있다.
