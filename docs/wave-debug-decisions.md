# 웨이브 디버그 기능 협의

## 사용자 확정

- 1/2/3/4: 해당 웨이브로 바로 이동한다.
- 디버그 웨이브 이동 시 기존 적을 모두 제거한다.
- 8: 근접 적만, 9: 원거리 적만, 0: 두 종류 모두.
- 종류 변경은 현재 적과 출현 대기 목록을 비우고 현재 웨이브를 처음부터 다시 생성한다.
- 웨이브 시작 때 각 통로 안에 적을 한 줄로 생성한다. 철창이 닫혀 있다가 상→우→하→좌 순서로 올라간다.
- 철창이 다 올라가면 좌우 입구는 진행 방향 쪽부터, 위쪽 입구는 발부터 적이 보인다.
  아래쪽 입구에서는 적의 머리가 아치 지붕 너머로 먼저 드러난다.
  경기장에 도착하는 순서는 상→우→하→좌를 0.24초 간격으로 반복한다. 도착하면 전투를 시작한다.
- 보스전은 이번 단계에서 구현하지 않는다.
- 4번은 적이 없는 4웨이브 대기 상태로 이동한다.
- Q: 적 없음 → 근접 1마리 → 원거리 1마리 → 적 없음 순서로 순환한다.
  각 모드 전환 시 적·탄환·대기열을 비우며, 단일 적은 북쪽 입구에서 한 마리만 생성한다.
  이 모드에서는 추가 출현이 없으며 주인공 상태를 유지한다.
  4웨이브 대기 중에도 Q로 단일 적을 시험할 수 있다.
- 1~4/8/9/0을 누르면 Q 단일 테스트를 끝내고 기존 웨이브 디버그로 돌아간다.

## 기획서의 초기 배치

- 혼합 1웨이브: 입구별 근접 1 + 원거리 1, 전체 8마리.
- 혼합 2웨이브: 입구별 근접 2 + 원거리 1, 전체 12마리.
- 혼합 3웨이브: 입구별 근접 3 + 원거리 1, 전체 16마리.
- 단일 종류 모드도 해당 웨이브 총 마릿수를 유지하고 종류 변경 시 전부 새로 생성한다.
- 원거리 적은 접근 후 사거리 안에서 예고 없이 직선 투사체를 발사한다.
  첫 발은 사거리 진입 직후, 이후에는 3초 간격. 유도·도주 없음. 패링에 스턴하지 않는다.

## 적용 수치와 전환 규칙

- 원거리 몸체 및 히트박스는 주인공과 동일한 2.4m × 4.8m.
- 원거리 체력 60, 이동 10km/h, 사거리 15m.
- 탄환은 속도 8m/s, 지름 1.4m, 피해 10, 패링당 에너지 10. 보라색 64×64 도트로 표시한다.
- 기본 방어·패링·플레이어 적중·광선 접촉·경기장 경계 도달 시 탄환 제거.
- 원거리 탄환의 패링은 근접 적 한 기 스턴 기회를 소비하지 않는다.
- 사용자 변경: 근접·원거리 적끼리는 전체 몸체 히트박스 사이에 최소 0.7m를 유지한다.
  추적 중에는 다른 적을 통과하지 않고 옆으로 돌아간다. 공격·스턴 중인 적도
  다른 적의 이동을 막지만, 사망한 적은 막지 않는다. 플레이어를 밀어내지는 않는다.
- 다리 끝이 막히면 주변의 빈 곳을 향해 걸음을 틀며 도착 순서와 간격을 유지한다.
- 이번 디버그 단계에서는 숫자 키로만 웨이브를 전환하며 자동 전환은 없다.
- 웨이브 이동 및 종류 재선택 시 기존 적·탄환·출현 대기열을 모두 비운다.
  주인공의 위치·체력·에너지는 유지한다. 같은 키를 다시 눌러도 재생성한다.
- R은 주인공 상태까지 초기화하고 1웨이브 혼합 구성으로 재시작한다.
- 일시정지 중에도 숫자 키로 시험 구성을 바꿀 수 있지만 전투/출현 시간은 흐르지 않는다.

데이터의 원본은 `data/waves.json`이며 생성된 `wave_data.py`를 직접 수정하지 않는다.
