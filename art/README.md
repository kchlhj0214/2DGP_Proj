# Shield Attack 외형 검토

최신 캐릭터 작업은 사용자가 선택한 **직접 그린 2D 도트** 방식이다.
`sprite-review/README.md`에서 스프라이트와 움직임을 확인할 수 있다. 게임 연결 전 검토 자료다.
아래 3D 모델과 모션은 이전 외형 자료로 보존한다.

## 실제 3D 모델

`model-review-v1/shield-attack-review.blend`에 주인공, 근접 해골, 원거리 해골을 보존했다.
각 모델의 `hero.glb`, `melee.glb`, `ranged.glb`도 함께 제공한다.
3D 모델과 장비는 기존 컨셉을 보고 직접 구성한 메시이며 평면 그림을 세운 것이 아니다.

- 주인공: 근육질 체형, 묶은 갈색 머리, 짧은 수염, 가죽·털 장비.
- 방패: 금속 테두리, 십자 보강대, 룬, 청록색 보석, 나무 뒷면과 손잡이.
- 근접형: 해골, 청동 투구, 한쪽 어깨 갑옷, 붉은 천, 칼.
- 원거리형: 해골, 자주색 후드와 망토, 보라색 수정 지팡이와 손 위의 룬.
- 보스는 이번 모델 검토 범위에 포함하지 않았다.

원본: `concepts/barbarian-appearance-v1.png`, `concepts/barbarian-relic-shield-v1.png`,
`concepts/skeleton-enemies-v1.png`, `concepts/enemy-scale-lineup-v1.png`.

## 방향과 2D 적용 준비

한 모델을 공통 카메라와 조명으로 45도씩 회전 촬영했다. 좌우 반전은 사용하지 않는다.
방패를 든 손, 칼과 지팡이 위치, 앞뒤 가림이 실제 입체 형태를 따른다.
모델은 미터 단위이며 발 기준점을 공유한다. 게임의 기존 0.9m × 1.8m 판정은 유지한다.

`*-turnaround.png`는 8방향 3D 확인 이미지이며, 최종 도트 스프라이트가 아니다.
`*-game-*.png`는 향후 게임 시점 선택을 확인하기 위한 저해상도 3D 렌더 실험이다.
최종 도트 해상도·팔레트·프레임과 리깅은 외형 승인 후 검증한다.

`data/art_models.json`이 색상·모델 목록·높이·카메라의 기준이다.
`tools/build_art_models.py`는 Blender 배경 실행 전용 제작 도구이고,
`tools/make_art_review_boards.py`는 실제 렌더를 확인판에 배치하는 제작 도구이다.
게임에는 제작 도구나 Blender가 필요하지 않으며 Python+pico2d 구성을 유지한다.

검증: 모든 참조 파일·필수 값 확인, 모델의 유한 좌표 확인, 3종 GLB 내보내기,
8방향 × 3종 × 두 시점의 투명 렌더 48장을 확인한다. 이미지 내용과 잘림을 별도로 검토한다.

## 2D 콜로세움 배경

`background-review-v1/colosseum.png`는 새로 만든 확인용 2D 이미지이다.
기존 선택 배경의 원본은 이 PC의 프로젝트, 원격의 모든 브랜치·추가 기록,
컨셉 자료 및 Patch 프로젝트 등록 자료에서 찾지 못했다.
다른 PC에서만 저장했거나 원격에 올리지 않은 파일은 이 환경에서 복구할 수 없다.

Patch 라이브러리의 barbarian, skeleton, arena, colosseum과 관련 블록을 검색하고
캐릭터 모델의 실제 썸네일을 비교했다. 검색된 캐릭터는 기존 컨셉과 비율이 달랐으며,
colosseum 결과는 HDRI로 게임용 원형 2D 배경에 맞지 않았다. 외부 라이브러리 파일을
이번 결과물에 사용하지 않았다.

배경은 내장 이미지 생성 도구로 제작했다. 3D 배경을 렌더한 것이 아니다.
중앙을 비운 원형 경기장, 네 방향 출입구, 낡은 석조 관중석, 모래색 바닥과 자주색 깃발을
기존 캐릭터 컨셉의 색감에 맞췄다. 현재 경기장 지름 63m와 충돌 경계에 맞춘 적용은 승인 후 진행한다.

최종 생성 프롬프트는 `background-review-v1/prompt.txt`에 보존한다.

## 로컬 제작 환경

최신 칼과 액션 검토는 `model-review-v3/README.md`를 참고한다. 사용자 선택 기사검은
Patch 라이브러리의 Polyfork Arming Sword를 사용했으며 원본·출처·라이선스는 `source/`에 있다.
패링, 주인공 피격, 근접 적 쓸어 베기와 피격을 작은 도트 크기에서도 비교한다.
이 단계는 확인용으로, 게임에는 아직 적용하지 않았다.

공식 Blender 4.5.9 LTS의 무료 휴대용 배포본을 `.scratch/tools`에 준비했다.
Blender는 화면 없이 CPU로 모델을 만들고 렌더했다. 클라우드 비용은 사용하지 않았다.
Blender 도구, 압축 파일, 로그와 라이브러리 썸네일은 Git과 게임 배포에서 제외한다.
