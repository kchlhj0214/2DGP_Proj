# 도형 전투 구현 협의

## 사용자 확정

- 기본 방어·패링: Space 대신 마우스 우클릭으로 변경.
  새 우클릭은 패링 시도, 1초 입력 잠금 후 유지 중이면 기본 방어.
- 조준: 마우스 방향. 광선 발사: 왼쪽 클릭.
- 근접 적: 주인공과 같은 크기, 직사각형 몸체 및 히트박스 2.4m × 4.8m.
- 칼 공격: 준비할 때 방향을 고정하고 전방 90도를 쓸어 벤다.
  베기 범위가 붉은 그라데이션으로 두 번 깜빡인다.
- 최초 전투 단계는 이미지 없이 방어·패링·광선과 근접 적 전투를 구현했다.
  후속 웨이브/원거리 추가 및 변경 규칙은 `docs/wave-debug-decisions.md`를 우선한다.

## 기획서에서 유지하는 규칙

- 기본 방어·패링은 전방 총 90도. 공격 ID별로 중복 처리하지 않는다.
- 패링 입력부터 위치 고정 0.5초, 재입력 잠금 1초. 잠금 중 입력을 예약하지 않는다.
- 첫 패링 성공부터 전 방향 무적 0.5초. 성공을 추가해도 무적을 연장하지 않는다.
- 첫 성공 때 전방 90도 안에서 몸체 간격이 2.4m 이내인 근접·원거리 적을 밀어낸다.
- 같은 패링 구간의 유효한 공격은 모두 축적하고, 근접 적 1기만 1.5초 스턴.
- 기본 방어와 무적으로 막은 공격은 축적하지 않는다.
- 축적은 자연 감소하지 않으며 일반 피격으로 사라지지 않는다.
- 광선 발사 순간 전량 소비. 발사 당시 에너지로 폭·피해를 고정한다.
- 광선 방향은 발사 순간 고정. 시작점은 플레이어 이동을 따라간다.
- 광선은 관통하며 경기장 끝까지 닿는다. 0/0.5/1초에 피해, 1.5초에 종료.
- 광선 중 통상 속도로 이동. 방어·재발사·취소 불가, 광선 자체의 무적 없음.
- 근접 적은 추적 → 방향 고정 및 예고 → 칼 휘두르기 → 후딜을 반복한다.
- 주인공은 방패를 들고 적보다 빠르게 움직이고, 달리면 더 빨라진다.

크기·카메라·일반 이동 속도에 관한 최신 사용자 결정은 AGENTS.md를 따른다.
## 적용한 초기 수치

사용자가 에너지 조건을 수정했으며 나머지는 제시한 테스트 초기값을 적용한다.
수치의 원본은 `data/combat.json`이다.

| 항목 | 수치 |
| --- | --- |
| 이동 속도 | 달리기 22 / 적 10 / 기본 방어 14km/h |
| 체력·피해 | 주인공 100 / 적 60 / 칼 피해 10 |
| 칼 | 길이 3.4m, 두께 1m, 전방 90도 |
| 적 행동 | 몸체가 맞닿기 0.45m 전부터 예고 0.6초, 휘두르기 0.25초, 후딜 0.8초 |
| 패링 구간 | 단계별 0.30 / 0.22 / 0.15 / 0.10초 |
| 패링 동작 | 방패를 0.11초에 들어 올림. 성공 순간 방패가 위로 튕김 |
| 축적 | 공격당 10, 최대 40 |
| 단계 | 0~9 / 10~19 / 20~29 / 30~40 |
| 광선 | 타격당 발사 전 축적량 × 0.5, 1~3단계 폭 2.1m, 4단계 폭 4.2m |
| 일반 피격 무적 | 사용자 수정으로 0.5초, 이 구간에는 에너지 축적 불가 |
| 훈련 | 최초 근접 적 3마리에서 웨이브 출현으로 변경. R로 전체 초기화. ESC로 일시정지/재개 |

광선은 동작 프레임마다 방패 보석 위치에서 출발한다. 둔각 삼각형으로 넓어진 뒤 단계별 폭을
유지하며 표시와 피해 판정에 같은 범위를 사용한다.

후속 원거리 단계에서는 기본 방어·패링·광선에 의한 투사체 제거도 검사한다.
