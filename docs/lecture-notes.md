## 이번 단계

- 확정: 원형 맵 지름 = 화면 높이 × 1.75.
- 확정: 플레이어 높이 = 화면 높이 × 0.05, 히트박스 가로:세로 = 1:2.
- WASD, 대각선 보정, 경계 제한은 기획서 기준을 따른다.
- 사용자 변경: 카메라의 가장자리 제한을 없애 플레이어를 항상 화면 중심에 둔다.
  원 밖에도 지면을 표시하되 이동할 수 없다. 맵 지름은 그대로 유지한다.
- 환산 기준: 화면 세로 36m → 플레이어 0.9 × 1.8m, 경기장 지름 63m.
- 사용자 변경: 기본 이동 속도는 기존 7km/h의 두 배인 14km/h.
- 위치·충돌은 m, 시간은 s로 계산하고 그릴 때만 pixel로 변환한다.
  따라서 720p/1080p에서 같은 초 동안 같은 거리와 같은 화면 비율로 이동한다.
- 히트박스는 회전하지 않는 직사각형이다. 경기장 경계는 하단 1/2 영역의
  네 꼭짓점이 원 안에 있도록 제한한다. 상단 1/2은 원 밖으로 나갈 수 있다.
  전체 히트박스와 경계 판정용 영역은 분리하며, 도형의 가운데 선으로 구분한다.
- 적 크기는 미확정이므로 이번 단계에 적과 전투를 추가하지 않는다.

데이터 수정 → `python tools/generate_data.py` 검증·상수 생성 → 검사 → 실행 순서를 따른다.
수치의 원본은 `data/scale.json`이다. 생성된 `game_data.py`를 직접 수정하지 않는다.
