# Shield Attack 2D 모션 검토

기존 컨셉을 참고해 평면 도트로 직접 그린 스프라이트다. 기본 자세의 캐릭터 키는 약 70픽셀이다.
방패는 주인공 왼팔, 기사검은 근접 적 오른손에 있으며, 여덟 방향의 장비 가림과 발 위치를 따로 표현한다.

- 방패 전사: 걷기, 달리기, 기본 방어 유지, 무릎을 굽혔다 펴며 낮은 방패를 올리는 패링.
- 근접 해골: 걷기, 달리기, 머리 위에서 내려치는 공격. 패링에 걸리면 공격의 접촉 자세에서 분기해 검이 위로 튕기고 두 걸음 물러난다.
- 원거리 해골: 걷기, 달리기, 지팡이로 즉시 발사한 뒤 자세를 낮추는 공격.

일반 피격 및 보스 동작은 이번 검토 범위에서 제외한다. 근접 적의 후퇴는 검이 패링에 막힌 경우에만 쓰는 동작이다.

`parry-and-recoil.gif`는 내려치는 적과 올려막는 주인공을 함께 보여준다.
`movement-and-attacks.gif`는 나머지 동작을, `directions.png`는 세 캐릭터의 여덟 방향을 보여준다.
아직 게임에 연결하지 않은 시안이며, 접촉 불꽃과 발사체는 장면 미리보기에서만 표시한다.

## 스프라이트 규격

`atlas.json`에 각 시트의 이름·프레임 수·반복 여부를 기록한다.
시트는 투명 PNG로 열은 시간, 행은 남·남동·동·북동·북·북서·서·남서 순서다.
각 칸은 144×144픽셀이며 왼쪽 위에서 (72, 102)가 바닥 기준점이다. 검토 재생 속도는 초당 16프레임이다.
패링에 막힌 적의 후퇴는 스프라이트에 그려져 있으므로 실제 이동으로 옮길 때 위치가 이중 적용되지 않게 한다.

동작 수치는 `data/sprite_motion.json`에서 편집한다. 제작 시에만 Pillow를 사용한다.
`tools/build_sprite_motion.py`는 시트를 생성하고 비어 있거나 잘리는 프레임과 공격 분기를 검사한다.
`tools/preview_sprite_motion.py`는 같은 시트에서 확인용 이미지와 GIF를 만든다.
